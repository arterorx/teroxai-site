# TeroxAI brand files

Source of truth: `src/components/Logo.astro`. Regenerate with `node` per the snippet in git history (commit "Brand files").

| File | Use |
|---|---|
| `teroxai-appstore-1024.png` | App Store Connect / developer artwork: 1024×1024, square, no transparency. Apple applies the rounded mask. |
| `teroxai-mark.svg`, `teroxai-mark-1024.png` … `-128.png` | The mark with rounded corners and transparent outside, for websites, docs, avatars. |
| `teroxai-mark-square.svg` | Square source without rounding, for anything that masks its own corners. |
| `teroxai-lockup.svg`, `teroxai-lockup.png` | Mark plus wordmark "TeroxAI". The SVG text uses the system font, so open it on a Mac or use the PNG. |

Colours: ink `#111111`, spark gradient `#C8894F → #7C5CFF`. Keep at least the mark's own width as clear space around it.
